Security

No user-account system. The Admin Key protects management endpoints. Keep it private. API binds to 127.0.0.1. Put Cloudflare Access in front of a Tunnel; never expose port 8765 publicly.

Current MVP

Paper create/list/start/stop/restart, console, basic text file editor, ZIP backups, memory and CPU-thread metrics. Not yet included: Fabric/Forge, plugin catalogue, restore UI, auto Cloudflare setup, TCP relay, live CPU percentage.
