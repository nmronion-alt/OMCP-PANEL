Routing & remote access

Panel access · Cloudflare Tunnel

The panel listens only on 127.0.0.1:8765. A Cloudflare Tunnel can publish this web panel without opening an inbound port.

Temporary test link

cloudflared tunnel --url http://127.0.0.1:8765

Quick Tunnels create a temporary trycloudflare.com URL. The URL changes and stops when cloudflared stops. The installer now starts this temporary tunnel automatically and writes its public URL to the Cloudflare tunnel log.

Persistent hostname

  1. Create a named tunnel in Cloudflare Zero Trust → Networks → Tunnels.
  2. Add a Published Application route to http://127.0.0.1:8765.
  3. Install cloudflared on this VPS and run it with the tunnel token from Cloudflare.
  4. Protect the hostname with Cloudflare Access.

Cloudflare official setup guide

Temporary Quick Tunnel starts from the installer; permanent hostname still needs a named tunnel and Cloudflare Access.
